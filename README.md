# Philosophers 🍝

A concurrency project in C based on the Dining Philosophers problem.

## About

The project explores multithreading, mutexes, synchronization, timing, and safe shared-resource access while preventing deadlocks and race conditions.

## Concepts

- POSIX threads
- Mutexes
- Concurrency
- Synchronization
- Race conditions
- Deadlock prevention
- Precise timing
